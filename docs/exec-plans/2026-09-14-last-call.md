# Last Call implementation

Build a standalone TypeScript npm CLI for macOS. The companion skill drives
configuration and inspection inside Claude Code or Codex. Native sessions run
one work item each; the skill owns its source of work.

Defaults: twelve hours before weekly reset, five percent weekly reserve,
five-minute foreground idle delay. Short-term limits gate admission. Manual
sprints bind to a measured provider period and an explicit deadline. Active
runs finish when admission closes.

Use configurable global slots, per-skill concurrency, and launch spacing. A
human handoff occupies its slot, while peers continue. Store receipts and
ownership in SQLite. Recover uncertain runs without replaying external work.

Use native lifecycle hooks for activity metadata, CodexBar CLI for quota, and
native authenticated execution with per-skill permission settings. Bind quota
and execution to the configured native account. Reject missing or stale quota.

Deliver onboarding, semantic-review guidance, launchd service control, optional
notifications and keep-awake, resumable answers, slot release, useful-output
review metrics, sample skills, and a release checklist.

Validation: deterministic scheduler tests, provider fixtures, hook preservation,
crash recovery, and controlled native child processes; then live provider and
workflow acceptance before publishing.

Implementation choices: Node's built-in SQLite avoids a native npm dependency.
One admission per poll provides a fresh activity/quota check between launches.
CodexBar v0.60.1 is installed with a pinned SHA-256 checksum. Hooks require an
observed native lifecycle event before enabling admission.
