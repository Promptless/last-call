# Prospect research

Inputs: a source of prospect work, its claim/update commands or tools, and an
output directory. If one is missing, report the missing input before selecting
work. The source may be a CRM, issue tracker, or a user-owned local queue.

1. Select and claim one prospect through the supplied source. Exclude completed,
   claimed, or awaiting-review records. If none remain, report no work.
2. Read the prospect's official product and documentation pages. Collect source
   URLs and distinguish observed facts from inferences.
3. Write an account brief in an output path unique to that prospect: what they
   sell, who uses it, a concrete documentation or integration observation, an
   outreach hypothesis, uncertainties, and citations. Draft outreach only when
   requested; leave sending to the human.
4. Check that the cited pages support the claims. Mark the external work item
   ready for review and return its reference and the brief path.

On missing access or ambiguous identity, preserve the claim, mark the item
awaiting input when supported, and return the specific question. Never claim
the research succeeded when sources could not be checked.
